A04-1151 — 雲端資料瀏覽

這個頁面已於 2026-09-10 停用。

為什麼停用

專題的雲端資料庫已從 Supabase 改為 MongoDB Atlas。

Supabase 有現成的 HTTP 介面與唯讀金鑰，網頁可以直接查詢，所以才有這一頁。 MongoDB 只接受官方驅動程式連線，瀏覽器發不出這種連線，這頁沒辦法照原樣搬過去。

不過現在三位組員都有 Atlas 帳號，用官方工具看到的是即時資料， 比這個頁面好，所以就不另做替代品了。

改用 MongoDB Compass

  1. 下載 MongoDB Compass（官方免費 GUI）
  2. 跟湯明祐要唯讀連線字串，貼進去連線
  3. 資料庫 hems 底下：
    load_forecast　← 負載預測（一份文件＝一次刷新，96 步在 steps 陣列裡）
    actual_load　　← 負載真實值

要看某一次刷新，在 load_forecast 的 filter 打：

{ refresh_time: ISODate("2010-11-18T12:00:00Z") }

要匯出請按 EXPORT DATA → Export query results → JSON， 會保留 96 步的陣列結構；選 CSV 會攤成一列 771 欄。

不想裝軟體

跟湯明祐要，他可以用 mongo_handoff/export_doc.py 直接匯出檔案給你。

註：時間欄照字面存（牆上時間），filter 裡的 Z 只是格式，不要自己加減 8 小時。
